Everything you need to go from zero to a running local environment.

## Install the CLI

Install the Astro CLI with your package manager, then scaffold a
project:

```bash
astro dev init
```

<Note>
The CLI needs Docker running locally.
</Note>

## Start the local environment

Run `astro dev start` to boot the local environment. The webserver
listens on port 8080 once all containers are healthy.

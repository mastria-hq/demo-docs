## Task retries

<ParamField path="retries" type="integer" default="2">
The number of times the scheduler retries a failed task before marking
it failed. The default is 2 retries.
</ParamField>

## Example DAGs

<ParamField path="load_examples" type="boolean" default="True">
Set `load_examples` to `False` in `airflow.cfg` to hide the example
DAGs from the UI.
</ParamField>
